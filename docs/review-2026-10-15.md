# Independent review of 1.2-1.6 (2026-10-15), outcome in 1.7

Reviewer: a separate Fable 5.1 agent, which only read and tested code (Docker, no network, no rotator). Scratch
reproductions: build-host/fable/ (not in git). It was preceded by my own review (1.6: CW7 right after a stop; a 16-bit
overflow in the slow-down limiter).

| # | Finding | Severity | Reproduced | 1.7 |
|---|---|---|---|---|
| 1 | S_RUN slow-down ignored register 6 (~1000 PWM/s, 1 PWM per pass); the sim check (+2 per call) could not see it | major | yes | fixed: persistent ramp toward the demand, speed-aware slow-down start (decel_pwm); the sim check accumulates over 300 ms |
| 2 | GE64 (reset during a move) survived only one boot; the next reset brought back a stale position with GE0 | major (since 1.0) | yes (simavr: 19.5 deg wrong, GE0) | fixed: slots keep MOVING while uncertain, the forced save is skipped |
| 3 | "need" started a move that S_RUN cut in the same tick: relays clicked, no motion | minor | yes | fixed: no "close" rule before the first edge |
| 4 | Counter parity never checked: one uncounted level change (e.g. a boot read glitch) left a permanent 0.2-0.8 deg error | minor | yes | fixed: resync at the next edge, PD y |
| 5 | An EMI burst >= 3 ms = two edges: +1.0 deg and an absurd speed (early stop) | minor | yes | fixed: pairs < 20 ms undone, PD z |
| 6 | tick() read ISR state in several separate reads: an edge in between could cut a landing early | minor | reasoning | fixed: one Snap per pass |
| 7 | set_raw() read the level outside the atomic block | minor | reasoning | fixed |
| 8 | pos_off only in the settings block: a torn settings write shifted the grid silently | minor | reasoning | fixed: pos_off in every position slot (SLOT_OFF) |
| 9 | Move start discarded a pending rest estimate (live position stepped back) | nit | yes | fixed: finish_rest() at start |
| 10 | No range check for a CRC-valid stored position | nit | reasoning | fixed: no position (ER_NOPOS) |
| - | avrtest stack margin used a fixed .data+.bss (too optimistic: 192 B real) | test | yes | fixed: from the ELF; log 64 -> 48 entries, margin 327 B |

would read tenths as counts (going back to 1.1 is not supported).
